How it works

  1. Detection finds where text is and draws a polygon around each line.
  2. Recognition reads the characters inside every polygon.
  3. Post-processing applies the confidence threshold and sorts lines into reading order.

Pick a photo and one or more engines. Each engine gets its own panel with the boxes it found, the text it read and how long every stage took.
